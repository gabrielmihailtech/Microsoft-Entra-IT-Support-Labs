# Lab 01 – User Account Investigation and Password Reset

## Objective
Investigate and resolve a Microsoft 365 account access issue for a new employee using Microsoft Entra ID and Microsoft 365 administration procedures.

## Scenario
John Smith, a new employee in the Finance Department, reported that he could not access Microsoft 365.

## Investigation and Resolution
1. Located the user account in Microsoft Entra ID.
2. Confirmed that the account was enabled.
3. Identified that no Microsoft 365 licence was assigned.
4. Verified the user's licence requirements and obtained approval.
5. Assigned Microsoft 365 Business Standard (with Teams).
6. Confirmed the licence assignment was successful.
7. Investigated the continued sign-in failure and identified a possible issue with the temporary password.
8. Verified the user's identity and reset the password.
9. Enabled the requirement to change the password at the next sign-in.
10. Confirmed that the user successfully accessed Outlook and Teams.

## Result
The user successfully signed in, changed the temporary password and accessed the required Microsoft 365 services.

**Ticket Status:** Resolved – Closed

## Skills Practised
- User account investigation
- Microsoft 365 licence management
- Password reset procedures
- User identity verification
- Troubleshooting and ticket documentation

*Training environment: Simulated. No changes were made to a real Microsoft Entra tenant.*
